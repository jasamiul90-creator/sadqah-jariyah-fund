# সদকায়ে জারিয়া মাসিক ফান্ড (Sadqah Jariyah Monthly Fund)

> **প্রতিটি অবদান হোক কল্যাণের পথে**  
> একটি আধুনিক, নিরাপদ ও জবাবদিহিতামূলক ইসলামিক মাসিক কল্যাণ তহবিল ব্যবস্থাপনা প্ল্যাটফর্ম।

## 📌 প্রকল্পের পরিচিতি (Project Overview)

**সদকায়ে জারিয়া মাসিক ফান্ড** হলো ২৫ জন সদস্যের একটি সুসংগঠিত ব্যক্তিগত ইসলামিক দাতব্য তহবিল। ফান্ডের কাঠামো:
- **১ জন প্রধান অ্যাডমিন (Md Samiul Islam):** একমাত্র তিনি অ্যাডমিন ড্যাশবোর্ডে প্রবেশ এবং সমস্ত আর্থিক হিসাব নিয়ন্ত্রণ করতে পারেন।
- **৪ জন কার্যকরী কমিটি সদস্য:** সাধারণ সদস্য ড্যাশবোর্ড ব্যবহারের অনুমতিপ্রাপ্ত (অ্যাডমিন ক্ষমতা নেই)।
- **২০ জন সাধারণ সদস্য:** শুধুমাত্র নিজস্ব মাসিক চাঁদা ও আর্থিক রেকর্ড দেখতে পারবেন।

প্রত্যেক সদস্যের জন্য মাসিক নির্ধারিত অনুদানের পরিমাণ ভিন্ন হতে পারে। ওয়েবসাইটটিতে সর্বোচ্চ নিরাপত্তা, ব্যক্তিগত তথ্যের গোপনীয়তা এবং স্বচ্ছ সামগ্রিক তহবিল পরিসংখ্যান নিশ্চিত করা হয়েছে।

## 🛠️ প্রযুক্তিগত বৈশিষ্ট্য (Technology Stack)

- **Frontend & Backend:** [Next.js](https://nextjs.org/) (App Router, Server Actions, Route Handlers)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (ইসলামিক গ্রিন ও এমারেল্ড থিম, মোবাইল-ফার্স্ট ডিজাইন)
- **Database & Auth:** [Supabase](https://supabase.com/) (PostgreSQL Cloud Database & Authentication)
- **Security:** Supabase Row Level Security (RLS) ও সার্ভার-সাইড রোল ভেরিফিকেশন
- **Charts:** Recharts (মাসিক আদায়, ব্যয় ও ফান্ড ব্যালেন্সের চিত্র)
- **Reports:** jsPDF & AutoTable (অফিসিয়াল PDF রিপোর্ট এবং Excel/CSV এক্সপোর্ট)
- **Deployment Ready:** Vercel

## 🔒 নিরাপত্তা ও স্বাধিকার (Security & RLS)

1. **একক অ্যাডমিন নীতি (Single Admin Policy):**  
   - কেবলমাত্র `Md Samiul Islam` অ্যাডমিন প্যানেলে প্রবেশ করতে পারেন।
   - অন্য কেউ (এমনকি কমিটি সদস্যগণও) অ্যাডমিন প্যানেলে প্রবেশ করতে পারবেন না। সার্ভার-সাইড গার্ড দিয়ে ৪-স্তরে এই অ্যাক্সেস সুরক্ষিত করা হয়েছে।
2. **ব্যক্তিগত তথ্যের গোপনীয়তা:**  
   - সাধারণ সদস্যগণ লগইন করার পর শুধুমাত্র নিজেদের জমার রেকর্ড, বকেয়া এবং পরিশোধের তারিখ দেখতে পান।
   - অন্য কোনো সদস্যের ব্যক্তিগত লেনদেন দেখা বা সম্পাদনা করা কোনো সদস্যের পক্ষে সম্ভব নয়।
3. **উন্মুক্ত সামগ্রিক হিসাব (Public Transparency):**  
   - `Fund Summary` পেজে মোট আদায়, মোট ব্যয় ও বর্তমান স্থিতি দৃশ্যমান। তবে কোনো একক সদস্যের ব্যক্তিগত চাঁদার পরিমাণ উন্মুক্ত পেজে প্রকাশ পায় না।
4. **Row Level Security (RLS):**  
   - `supabase/schema.sql` ফাইলে প্রতিটি টেবিলের জন্য কঠোর RLS পলিসি কনফিগার করা আছে।

## 🚀 লোকাল সেটআপ ও চালানো (Local Development)

### ১. ডিপেন্ডেন্সি ইনস্টলেশন
```bash
npm install
```

### ২. এনভায়রনমেন্ট ফাইল কনফিগারেশন
`.env.local` ফাইল তৈরি করুন:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key

NEXT_PUBLIC_APP_URL=http://localhost:3000
ADMIN_EMAIL=admin@sadqahfund.org
```

### ৩. ডেভেলপমেন্ট সার্ভার চালু
```bash
npm run dev
```
ব্রাউজারে দেখুন: [http://localhost:3000](http://localhost:3000)

### ৪. প্রোডাকশন বিল্ড
```bash
npm run build
npm start
```

## 🗄️ Supabase ডাটাবেজ সেটআপ গাইড

সম্পূর্ণ SQL স্ক্রিপ্ট `supabase/schema.sql` এবং `supabase/seed.sql` ফাইলে প্রস্তুত রয়েছে।

1. [https://supabase.com](https://supabase.com)-এ একটি নতুন প্রজেক্ট তৈরি করুন।
2. Supabase ড্যাশবোর্ডের **SQL Editor**-এ যান।
3. `supabase/schema.sql` ফাইলটির সম্পূর্ণ কোড কপি করে Run করুন।
4. `supabase/seed.sql` ফাইলটির কোড কপি করে Run করুন (২৫ জন সদস্য তৈরি হবে)।
5. **Authentication** -> **Users** থেকে অ্যাডমিনের জন্য একটি ইউজার অ্যাকাউন্ট তৈরি করুন (`admin@sadqahfund.org`)।
6. SQL দিয়ে auth_user_id লিংক করে নিন:
   ```sql
   UPDATE profiles SET auth_user_id = '<COPIED_AUTH_USER_UUID>' WHERE email = 'admin@sadqahfund.org';
   ```

## 🌐 Vercel-এ ডিপ্লয়মেন্ট নির্দেশিকা (Deploy to Vercel)

1. এই প্রজেক্টটি আপনার GitHub / GitLab রিপোজিটরিতে পুশ করুন।
2. [Vercel](https://vercel.com)-এ লগইন করে **"Add New Project"** সিলেক্ট করুন।
3. রিপোজিটরিটি সিলেক্ট করুন। Next.js প্রজেক্ট স্বয়ংক্রিয়ভাবে শনাক্ত হবে।
4. **Environment Variables** সেকশনে নিচের ভেরিয়েবলগুলো যুক্ত করুন:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `NEXT_PUBLIC_APP_URL` (আপনার Vercel ডোমেন)
   - `ADMIN_EMAIL` (admin@sadqahfund.org)
5. **"Deploy"** বোতামে ক্লিক করুন। ১-২ মিনিটের মধ্যে লাইভ হয়ে যাবে!
